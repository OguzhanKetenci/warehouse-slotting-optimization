# Data

**Source:** [Online Retail II – UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii)

Real transaction data from a UK-based online retailer whose customers are largely wholesalers (2009–2011). Only the `Year 2010-2011` sheet (last 12 months) is used.

1. Download `online_retail_II.xlsx` from the link above.
2. Place it at `data/raw/online_retail_II.xlsx`.

Raw and processed data are not committed to this repository (see `.gitignore`).
